Datenschutzerklärung

Diese Seite gehört zum Projekt „Dinge Durchschaut“. Diese Website selbst setzt keine Cookies, nutzt kein Tracking und speichert keine Daten über Besucher. Beim Aufruf übermittelt dein Browser technisch bedingt seine IP-Adresse an den Hosting-Anbieter GitHub Pages (GitHub Inc., USA), der sie in Server-Logs verarbeiten kann.

Die App „Dinge Durchschaut“ (Google/YouTube-Zugriff)

Die App wird ausschließlich vom Betreiber des Kanals „Dinge Durchschaut“ genutzt, um eigene Videos auf den eigenen YouTube-Kanal hochzuladen. Sie ist nicht für die Öffentlichkeit gedacht. Es werden keine Daten anderer Nutzer erhoben, gespeichert, weitergegeben oder verkauft. Die Nutzung von Daten aus Google-Diensten folgt der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung.
